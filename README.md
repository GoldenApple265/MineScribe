# MineScribe
Easily turn text into a Minecraft book with these simple Python scripts. There are two modes, copy paste mode and Scholar formatting mode. All you have to do is put some text in the input file and run the script for your preferred mode. The formatted text will be put in the output file.

Ensure that paragraphs in the input file have no blank lines between them. The scripts will automatically add a blank line between every paragraph so that they are easy to differentiate.

Note that this is designed for Minecraft Java Edition books. Copy and paste mode works for Bedrock Edition, but the pages will not be filled all the way because Bedrock Edition pages have more space than Java Edition. 

### Copy and Paste
Segments the input text into pages that can easily be copy and pasted straight into a Minecraft book

### Scholar Formatting
Creates a .txt file that can be easily imported into a Minecraft book using the Scholar mod by Mortuusars
